# SoC25 - Building a GPT Bot
Videos for Milestone 4, 5, 6 are in the respective folder
## Milestone projects:
### Milestone 1: Similar Sentence Finder
Uses Word2Vec embeddings to find the 5 most similar sentences to the input
### Milestone 2: Sentiment Analysis
Leverages an LSTM model in order to classify movie revies as good or bad
### Milestone 3: Sentiment analysis with BERT
Uses Google BERT in order to create sentence embeddings for an LSTM model
### Milestone 4: Simple Gemini Frontend
A simple NodeJS app that sets up a simple chat with Google Gemini using its API
### Milestone 5: IITB UG Rulebook helpdesk
Implements a Langchain and Gemini based RAG pipeline, with local vectorstores and indexing to create a QA interface for the IITB UG Rulebook
### Milestone 6: Law Bot
A RAG based bot for queries about Indian Law and constitution, ensuring data security by using OLlama in order to run Google Gemma locally as the backend
